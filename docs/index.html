Política de Privacidad

Tres en Raya Online

Última actualización: 26 de julio de 2026

🔒 Resumen simple: Esta aplicación no recopila, almacena ni comparte ningún tipo de información personal. Las partidas multijugador se conectan directamente mediante un código de sala temporal.

1. Información que recopilamos

Ninguna. El juego está diseñado exclusivamente para permitir partidas en directo entre dos jugadores mediante el uso de un código de sala compartido.

  • No solicitamos registro ni creación de cuentas.
  • No recopilamos nombres reales, direcciones de correo electrónico ni datos de contacto.
  • No almacenamos ubicaciones ni identificadores únicos de dispositivos.
  • No utilizamos cookies de rastreo ni servicios de analítica publicitaria.

2. Funcionamiento de las Partidas en Línea

Para conectar a dos jugadores en una partida, la aplicación utiliza una clave o código de sala generado temporalmente:

  • Códigos de sala: Son identificadores efímeros utilizados únicamente para emparejar a los dos jugadores en el servidor de juego durante el tiempo que dure la partida.
  • Datos de juego en memoria: El estado del tablero (movimientos de fichas) se transmite en tiempo real y se descarta inmediatamente al finalizar o desconectar la partida.

3. Servicios de Terceros

El juego puede utilizar servicios de infraestructura de red (como servidores de retransmisión o conectividad multijugador de Unity) con el único fin de establecer la comunicación entre jugadores. Estos servicios únicamente procesan el tráfico de red necesario para la partida sin recopilar información personal identificable del usuario.

4. Privacidad de los Menores

Al no recopilar ningún tipo de datos personales de ningún usuario, esta aplicación cumple con las normativas de protección de menores (como COPPA y GDPR) y es apta para todas las edades.

5. Cambios a esta Política

Nos reservamos el derecho de actualizar esta política de privacidad si en el futuro se incorporan nuevas funciones al juego. En caso de realizarse cambios, se actualizará la fecha en la parte superior de esta página.
